# libFredGI – gamma index library

The following files in this folder are compiled builds of **libFredGI 4.6**, the gamma index library
written by Angelo Schiavi for the FRED Monte Carlo project:

| File | Platform |
|---|---|
| `libFredGI.so` | Linux, x86_64 |
| `libFredGI.dll` | Windows, x86_64 |
| `libFredGI.dylib` | macOS 11 or newer, universal (Apple Silicon and Intel) |

Copyright © A. Schiavi and the FRED collaboration.

Their source code is not public. They are not covered by the GNU General Public License of FREDtools
(see [LICENSE](../../LICENSE) in the repository root); FREDtools calls them through their C interface.
