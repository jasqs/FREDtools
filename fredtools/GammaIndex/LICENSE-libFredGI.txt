libFredGI - gamma index library
===============================

[DRAFT - the wording of this notice is to be confirmed by A. Schiavi]

The files libFredGI.so (Linux, x86_64), libFredGI.dll (Windows, x86_64) and
libFredGI.dylib (macOS 11 or newer, universal: Apple Silicon and Intel) in this
folder are compiled builds of libFredGI 4.5, the gamma index library written by
Angelo Schiavi for the FRED Monte Carlo project.

Copyright (c) A. Schiavi and the FRED collaboration.

These libraries may be used free of charge, and redistributed unmodified
together with FREDtools. Their source code is not public. They are not covered
by the GNU General Public License of FREDtools (see LICENSE in the repository
root); FREDtools calls them through their C interface.

The libraries are provided "as is", without warranty of any kind.

Origin: release v4.5 of the libFredGI repository (built and tested by GitHub
Actions on Linux, Windows and macOS).
